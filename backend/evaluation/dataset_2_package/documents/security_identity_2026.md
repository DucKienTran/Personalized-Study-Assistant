# ASTER SECURITY & IDENTITY — 2026

All Aster plans support two-factor authentication.

## SSO
SAML Single Sign-On is included with Aster Enterprise and Aster Enterprise Plus.
Aster Lite does not include SAML SSO.

## Session security
Enterprise sessions expire after 12 hours of inactivity.
Lite sessions expire after 4 hours of inactivity.

## Encryption
Data at rest uses AES-256 encryption.
Data in transit uses TLS 1.3.

This document does not specify customer-managed encryption keys.
