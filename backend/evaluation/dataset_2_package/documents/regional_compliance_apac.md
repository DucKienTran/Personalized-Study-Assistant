# ASTER APAC COMPLIANCE NOTE — 2026

This note applies only to customers whose billing region is APAC.

Enterprise and Enterprise Plus customers in APAC may request that primary storage remain in the Singapore region.

The APAC note does not alter:
- renewal grace periods;
- member limits;
- workspace limits;
- support response targets;
- backup schedules.

Aster Lite does not provide selectable data residency under this note.
